# Fakeip-filter

![release](https://img.shields.io/github/v/release/Cryzhovnic/Fakeip-filter)
![last commit](https://img.shields.io/github/last-commit/Cryzhovnic/Fakeip-filter)

Готовый список доменов для `fake-ip-filter` в **Mihomo** (Clash.Meta). Домены из списка получают **реальный IP**, а не адрес из fake-ip пула. Это нужно там, где подмена адреса ломает работу: синхронизация времени (NTP), STUN/WebRTC, локальная сеть, проверка подключения Windows, игровые консоли и лаунчеры, музыкальные сервисы, роутеры и т. п.

Список собирается автоматически раз в сутки из двух публичных источников, очищается от дублей и избыточных правил и проверяется на настоящем Mihomo перед публикацией.

## Файлы

| Файл | Что это |
|---|---|
| `rules/fakeip-filter.mrs` | Бинарный формат Mihomo (`behavior: domain`, `format: mrs`). Компактный и быстрее грузится. |
| `rules/fakeip-filter.list` | Тот же список в текстовом виде, по одному правилу в строке. |
| `rules/fakeip-filter.stats` | Служебный файл сборки (число правил в источниках), для использования не нужен. |

Свежие файлы также лежат в [релизах](../../releases/latest). В описании каждого релиза есть сводка: сколько правил пришло из источников, сколько убрано как избыточные и результат проверки на Mihomo.

## Подключение

В конфиге Mihomo:

```yaml
rule-providers:
  fakeip-filter:
    type: http
    behavior: domain
    format: mrs
    url: "https://github.com/Cryzhovnic/Fakeip-filter/releases/latest/download/fakeip-filter.mrs"
    path: ./ruleset/fakeip-filter.mrs
    interval: 86400

dns:
  enable: true
  enhanced-mode: fake-ip
  fake-ip-filter:
    - "rule-set:fakeip-filter"
```

Другие варианты ссылки:

- из репозитория: `https://raw.githubusercontent.com/Cryzhovnic/Fakeip-filter/main/rules/fakeip-filter.mrs` 
- текстовый список: то же самое, но `fakeip-filter.list` и `format: text`.

> Важно: по умолчанию `fake-ip-filter-mode` равен `blacklist`, и домены из списка получают реальный IP. Если ты включил режим `whitelist`, смысл списка инвертируется: домены из него, наоборот, получат fake-ip.

## Как собирается

1. Скачиваются два источника (ниже), строки нормализуются: пробелы по краям, регистр, комментарии.
2. Дубли убираются. Затем убираются избыточные правила: те, которые целиком покрыты другим правилом-маской (например, `+.stun.*.*` уже покрывает `stun.example.com`, а `+.example.com` покрывает `*.example.com`).
3. Список конвертируется в `.mrs` самим Mihomo.
4. Реальный Mihomo запускается с этим списком в режиме fake-ip, и ему по DNS отправляются домены из списка (в том числе убранные как избыточные). Домены из фильтра не должны получить адрес из `198.18.0.0/16`, а контрольные домены вне списка должны.
5. Дополнительные защиты: сборка останавливается, если в источниках подозрительно мало правил или их число упало больше чем на 30% к прошлому запуску.
6. Коммит и релиз создаются, только если список изменился.

Расписание: ежедневно в 04:17 UTC (также можно запустить вручную).

## Как работают маски

Список использует синтаксис доменных масок Mihomo:

| Маска | Что матчит |
|---|---|
| `example.com` | только `example.com` |
| `*.example.com` | один уровень поддомена: `a.example.com`, но не `a.b.example.com` и не `example.com` |
| `.example.com` | любые поддомены, но не сам `example.com` |
| `+.example.com` | сам `example.com` и любые поддомены |
| `*` | имена без точки, например `localhost` |

`*` можно использовать и внутри домена, например `time.*.com` или `+.stun.*.*`. Если ты вручную перечисляешь такие маски прямо в YAML-конфиге, оборачивай их в кавычки, иначе YAML может неправильно их разобрать.

## Источники

Список строится из двух публичных списков. Все права на исходные данные принадлежат их авторам:

- [DustinWin/ruleset_geodata](https://github.com/DustinWin/ruleset_geodata): `fakeip-filter.list` (релиз `mihomo-ruleset`);
- [wwqgtxx/clash-rules](https://github.com/wwqgtxx/clash-rules): `fakeip-filter.list`.

## Совместимость

`.mrs` понимает только Mihomo. Для других ядер используй текстовый `fakeip-filter.list`, но проверь поддержку масок в твоём клиенте: `*` внутри домена и `+.` умеют не все.

## Нашёл проблему?

Если домен, которому нужен реальный IP, получает fake-ip (или наоборот), создай [issue](../../issues) с доменом и версией Mihomo.
